# Ekansh Bansal — Personal Portfolio & Field Notes

> *"Building useful things with code. Learning something new every day."*

An award-winning editorial personal portfolio for **Ekansh Bansal**, 2nd-Year Computer Science and Engineering student at **Mirai School of Technology**. Built with React, Vite, and Vanilla CSS, drawing creative direction from [Sarthak Sharma's Portfolio](https://sarthak-sharma-portfolio-six.vercel.app/) and [Christen Dijoux](https://christendijoux.com/).

---

## 🌟 Key Features

* **Authentic Visual Identity:** Features Ekansh's authentic mountain photograph framed in an editorial Archival Scientific Plate.
* **10-Chapter Editorial Narrative:** Continuous, story-driven flow connecting computer science fundamentals (C++ & DSA) to full-stack engineering and applied artificial intelligence.
* **Interactive Discipline Explorer (`SignalExplorer`):** Dynamic tabbed perspective switcher (*System Logic*, *Interface Architecture*, *Applied Intelligence*) with generative vector diagrams and domain insights.
* **Detailed Project Case Studies:** Realistic browser mockups showcasing:
  * **ForecastGuard AI:** Medium-range weather forecast bust detection and uncertainty analytics.
  * **Employee Management System:** Full-stack MVC application built with Node.js, Express, EJS, and MongoDB.
  * **Task Flow & State Synchronization:** Deep dive into native JavaScript DOM APIs, event bubbling, and state persistence.
  * **The Open-Source Sandbox:** GitHub practice repositories covering DSA and data science.
* **Methodology Accordion:** Engineering mental models (*First Principles*, *Build to Verify*, *Respect the User's Attention*).
* **Domain-Filtered Stack Matrix:** Clean technical capabilities grouped by category with zero arbitrary percentages.
* **The Trajectory:** 4-stage chronological timeline charting the path from first lines of C++ to future software ambitions.
* **The Dispatch Contact Suite:** Live internship availability beacon, one-click email copy with visual feedback, and verified links to LinkedIn and GitHub.

## 🛠️ Tech Stack & Design System

* **Framework:** React 19 + Vite
* **Styling:** Custom Vanilla CSS Design System with CSS variables
* **Typography:**
  * Display Serif: `Instrument Serif` (Google Fonts)
  * Body & UI: `DM Sans` (Google Fonts)
  * Telemetry & Code: `Geist Mono`
* **Color Palette:**
  * Canvas: Obsidian Ink (`#0B0F12`)
  * Surfaces: Alpine Spruce (`#152820`)
  * Text: Warm Ivory (`#EDE9DF`)
  * Accent 1: Glacial Sky Blue (`#8EBBE5`)
  * Accent 2: Alpine Burgundy (`#743C46`)
* **Icons:** Lucide Icons + Custom SVG Vectors

## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Start the local development server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser.

---

## 📦 Building for Production

```bash
# Create optimized production bundle
npm run build

# Preview production build locally
npm run preview
```

---

## 🌐 Deploying to Vercel / Netlify

1. Push this repository to GitHub: `https://github.com/ekanshbannsal/portfolio`
2. Connect your GitHub repository to [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
3. Set the build settings:
   * **Build Command:** `npm run build`
   * **Output Directory:** `dist`
   * **Install Command:** `npm install`
4. Click **Deploy**!
